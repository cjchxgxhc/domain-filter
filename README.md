## 规则列表

- **Ads Lite** — 自用的轻量手机补充规则片段。  
  `AdBlock - Hosts` - [查看详情](data/rules/ads_lite)
- **Ads Hosts** — 由系统底层网络服务读取并生效，有一定局限性。  
  `Hosts` - [查看详情](data/rules/ads_hosts)
- **Ads Proxy** — 用于代理程序的拦截列表。  
  `Clash` - [查看详情](data/rules/ads_proxy)
- **Proxy** — 所有需要被代理分流的域名。  
  `Clash` - [查看详情](data/rules/proxy)
- **Direct Fix** — 修复可能被proxy组错误分流的直连域名。  
  `Clash` - [查看详情](data/rules/direct_fix)
- **Adblock Extra Rules** — 元素隐藏规则与非域名网络规则聚合（已剔除纯域名拦截规则）  
  `Adblock` - [查看详情](data/rules/adblock_extra)
- **AdGround Home Extra Rules** — 白名单/特殊格式  
  `Adblock` - [查看详情](data/rules/adguard_home_extra)
